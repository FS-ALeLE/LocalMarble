# LocalMarble 기획서 — 「홍성 탐험 고고!」

> 지역 행사 부스에서 초등학생이 주사위를 굴려 지도를 돌며, 그 지역 퀴즈와 미니게임으로 지역을 배우는 디지털 보드게임.
> 첫 지역: **충청남도 홍성군**
> 구조 참고: 아케이드 퀴즈 게임 「데이트 퀴즈 고고」(SemiCom, 1998). 지도를 이동하며 장소별 퀴즈와 미니게임을 풀고, 라이프가 줄어드는 구조.

---

## 1. 기획 목표

| 항목 | 내용 |
|---|---|
| 대상 | 초등학생 (저학년 1~3학년 / 고학년 4~6학년 난이도 분리) |
| 사용 환경 | 행사 부스. 터치스크린 태블릿, 키오스크 또는 노트북 + 대형 모니터 |
| 1판 시간 | **5~7분**. 대기 줄이 생기는 행사 특성을 고려 |
| 학습 목표 | 홍성의 역사 인물, 문화유산, 특산물, 자연, 생활 안전을 놀이로 접함 |
| 확장성 | 지역 데이터(지도, 장소, 문항)를 **지역 팩**으로 분리해 다른 시·군으로 확장 (LocalMarble = Local + 부루마블) |

## 2. 핵심 게임 흐름

```
[타이틀] → [난이도·캐릭터 선택] → [보드 진행 루프] → [결과·도장판] → [보상 안내]
                                   │
                                   ├─ 주사위 굴리기 (1~3)
                                   ├─ 이동 (갈림길이면 방향 선택)
                                   ├─ 도착 칸 이벤트
                                   │    ├─ 장소 칸 → 테마 퀴즈 또는 미니게임
                                   │    ├─ 찬스 칸 → 랜덤 카드
                                   │    └─ 특수 칸 → 워프·휴식·함정
                                   ├─ 점수·라이프·도장 갱신
                                   └─ 종료 조건 확인
```

### 2.1 기본 규칙

- **주사위**: 1~3. 화면의 큰 주사위를 터치하면 굴러감. 칸 수가 작으므로 보드는 20~26칸 정도로 촘촘하게 설계.
- **라이프**: ♥ 3개로 시작. 퀴즈 오답 또는 미니게임 실패 시 1개 감소.
- **점수(탐험 점수)**: 정답, 미니게임 성공, 찬스 카드로 획득.
- **홍성 도장(스탬프)**: 테마 장소에서 **처음 정답**을 맞히면 그 장소의 도장을 획득. 학습 동기를 주는 수집 요소.
- **종료 조건** (먼저 해당되는 것)
  1. 도장 **5개**를 모은 뒤 **골인 지점(홍주읍성 조양문)** 에 도착 → **완주 성공**
  2. 라이프 0 → 게임 오버. 그때까지의 점수와 도장으로 결과 화면
  3. 턴 제한(기본 12턴) 초과 → 시간 종료. 결과 화면
- **이어하기 없음**: 행사 회전율을 위해. 대신 게임 오버 시 "오늘 배운 홍성 이야기" 요약 카드를 보여 줌.

### 2.2 「데이트 퀴즈 고고」 요소 대응표

| 원작 요소 | 이 게임에서의 대응 |
|---|---|
| 데이트 상대의 호감도 | **홍성 안내 캐릭터의 "친해지기 게이지"**. 정답이 쌓이면 캐릭터 대사·표정이 바뀌고 엔딩이 달라짐 |
| 장소마다 다른 퀴즈 | 장소마다 **테마 카테고리** 문항 풀 |
| 퀴즈 사이 미니게임 | 특정 장소는 **미니게임 전용**, 일부 장소는 퀴즈와 미니게임 랜덤 |
| 라이프 | ♥ 3개 |
| 1~2인 플레이 | 기본은 1인. **2인 번갈아 하기(핫시트)** 모드는 2차 개발 |

> 원작의 캐릭터, 그래픽, 명칭은 사용하지 않고 구조만 참고합니다(저작권).

### 2.3 안내 캐릭터 (예시)

- **"홍이"와 "주니"**: 홍주(홍성의 옛 이름)에서 따온 이름의 탐험 안내자. 선택한 캐릭터가 말풍선으로 문제를 내고 해설을 읽어 줌.
- 홍성군 공식 캐릭터 사용 여부는 군청과 협의(라이선스 확인 필요).

## 3. 지도(보드) 설계

### 3.1 형태

- 홍성군 실제 지도를 단순화한 **일러스트 맵** 위에 칸을 배치.
- **순환 경로 + 갈림길 2곳**: 갈림길에서 아이가 방향을 고르게 해 "탐험하는 느낌"을 줌.
- 서쪽(바다: 남당항, 스카이타워) / 중앙(홍성읍: 홍주읍성, 시장) / 북쪽(내포신도시, 용봉산) / 남쪽(광천, 오서산) / 동쪽(홍동, 이응노의 집)처럼 **실제 위치 관계를 지켜** 지리 감각도 함께 익히게 함.

### 3.2 장소 칸 목록 (요청한 장소 + 홍성 특색)

| 장소 유형 | 홍성 이름(안) | 실제 연결 | 테마 / 활동 |
|---|---|---|---|
| 도서관 | **만해 도서관** | 만해 한용운 (결성면 출생, 「님의 침묵」) | 국어·인물: 시인·독립운동가 이야기, 낱말 퀴즈 |
| 경찰서 | **백야 안전지킴이 경찰서** | 백야 김좌진 장군 (갈산면 출생, 청산리 전투) | 생활 안전·교통 규칙 퀴즈 + 김좌진 장군 인물 퀴즈 |
| 박물관 | **홍주성 역사관** | 홍주읍성, 홍주의병 | 역사 퀴즈 (홍주의 옛 이름, 의병, 읍성 구조) |
| 골목길 | **광천 토굴 새우젓 골목** | 광천 토굴 새우젓, 독배마을 | 미니게임 「새우젓 항아리 쌓기」 + 특산물 퀴즈 |
| 경기장 | **홍주 종합경기장** | 홍성 종합운동장 | 미니게임 전용: 「달리기 연타」, 「대하 잡기」 |
| 항구 | **남당항 바다 시장** | 대하·새조개 축제 | 바다 생물 퀴즈, 미니게임 「대하 잡기」 |
| 산 | **용봉산 바위길** | 용봉산 (기암괴석), 오서산 억새 | 자연·지리 퀴즈, 미니게임 「길 찾기」 |
| 관청 | **내포 도청 광장** | 충남도청 소재지(내포신도시) | 우리 지역 사회: 도청이 하는 일, 충남의 시·군 |
| 미술관 | **고암 이응노의 집** | 이응노 화백 생가 기념관 (홍북읍) | 미니게임 「같은 그림 찾기 / 틀린 그림 찾기」 |
| 시장 | **홍성 전통시장 장터** | 홍성·광천 5일장 | 미니게임 「장보기 계산」 (저학년: 덧셈, 고학년: 거스름돈) |
| 학교·마을 | **홍동 유기농 마을** | 유기농업 특구, 풀무학교 | 환경·농업 퀴즈 (오리 농법 등) |
| 전망대 | **홍성 스카이타워** | 서부면 해안 전망대 | 보너스 칸: 점수 +, 다음 주사위 한 번 더 |
| 생가·유적 | **성삼문·최영 장군 이야기길** | 사육신 성삼문, 최영 장군 관련 유적 | 인물 짝 맞추기 미니게임 |

> ⚠️ 모든 지명·인물·사실은 제작 단계에서 **홍성군청 문화관광 자료, 홍주성역사관 자료로 반드시 확인**합니다(5장 참고). 위 표는 기획용 초안입니다.

### 3.3 특수 칸

| 칸 | 효과 |
|---|---|
| **출발 / 골인 (홍주읍성 조양문)** | 출발점. 도장 5개 이상일 때 지나거나 멈추면 완주 |
| **찬스 카드 ("홍성 보물 쪽지")** | 랜덤: 점수 +50 / 라이프 +1 / 주사위 다시 / 원하는 장소로 이동 / 짧은 상식 쪽지(점수 없이 지식만) |
| **홍성역 (워프)** | 장항선 기차를 타고 다른 홍성역 연결 칸(예: 내포 쪽)으로 순간이동 |
| **쉼터 (정자)** | 한 턴 쉬기 대신 라이프 +1 (최대 3) |
| **갯벌 (함정)** | 발이 빠져 1칸 뒤로. 대신 갯벌 생물 짧은 상식 표시 |

**칸 배분 예시 (24칸)**: 장소 칸 14 / 찬스 4 / 워프 2 / 쉼터 2 / 함정 1 / 출발·골인 1

## 4. 퀴즈 · 미니게임 설계

### 4.1 퀴즈 형식

| 형식 | 설명 | 주 대상 |
|---|---|---|
| **O/X** | 두 개의 큰 버튼 | 저학년 |
| **3지선다 / 4지선다** | 그림 보기 포함 가능 | 공통 |
| **사진 보고 맞히기** | 유적·특산물 사진 → 이름 | 공통 |
| **순서 맞히기** | 사건 순서, 새우젓 만드는 과정 등 드래그 정렬 | 고학년 |

- **제한 시간**: 저학년 20초, 고학년 15초. 시간 막대 표시.
- **힌트**: 게임당 1회 "홍이의 힌트"(오답 보기 하나 지우기).
- **정답 해설**: 맞혀도 틀려도 **해설 1~2문장**을 반드시 보여 줌. 학습 효과의 핵심.
- **음성 읽기(TTS)**: 문제와 해설을 읽어 주는 버튼. 한글 읽기가 느린 저학년용.

### 4.2 문항 랜덤 배치 방식

1. 각 장소 칸은 `category`(카테고리)를 가짐. 예: `history`, `people`, `safety`, `specialty`, `nature`, `society`, `environment`
2. 게임 시작 시 선택한 난이도의 문항 풀에서 카테고리별로 **섞은 덱**을 만듦.
3. 그 칸에 멈추면 해당 카테고리 덱에서 **중복 없이** 한 문항을 뽑음(한 판 안에서 같은 문제 안 나옴).
4. 덱이 비면 다시 섞어서 사용.
5. "퀴즈 또는 미니게임" 칸은 정해진 비율(예: 퀴즈 70%, 미니게임 30%)로 결정.
6. 행사 당일 같은 문제가 너무 자주 나오지 않도록 **문항별 출제 횟수를 기기에 기록**하고 적게 나온 문항에 가중치를 줌(선택 기능).

### 4.3 미니게임 목록 (터치 한두 번으로 되는 30초 이내 게임)

| 이름 | 장소 | 조작 | 성공 조건 |
|---|---|---|---|
| 대하 잡기 | 남당항, 경기장 | 튀어 오르는 대하를 터치 | 20초 안에 10마리 |
| 새우젓 항아리 쌓기 | 광천 골목 | 타이밍 맞춰 터치해 쌓기 | 5층 쌓기 |
| 달리기 연타 | 경기장 | 버튼 빠르게 연타 | 정해진 시간 안에 결승선 |
| 같은 그림 찾기 | 이응노의 집 | 카드 뒤집기 짝 맞추기 | 제한 시간 안 4쌍 |
| 틀린 그림 찾기 | 홍주성 역사관 | 두 그림 비교 터치 | 3곳 찾기 |
| 인물 짝 맞추기 | 이야기길 | 인물 ↔ 업적 연결 | 3쌍 모두 정답 |
| 장보기 계산 | 전통시장 | 숫자 버튼 | 정답 입력 |
| 용봉산 길 찾기 | 용봉산 | 갈림길 미로를 손가락으로 따라가기 | 정상 도착 |

- 실패해도 라이프만 1 깎이고 **짧은 상식 한 줄**은 보여 줌.
- 1차 개발(MVP)에는 미니게임 **3개**(대하 잡기, 같은 그림 찾기, 장보기 계산)만 구현.

### 4.4 점수 · 보상

| 행동 | 점수 |
|---|---|
| 퀴즈 정답 | +100 (힌트 사용 시 +50) |
| 빠르게 정답(남은 시간 절반 이상) | +30 보너스 |
| 미니게임 성공 | +150 |
| 도장 첫 획득 | +50 |
| 완주 보너스 | +300 + 남은 라이프 × 100 |

- **결과 화면 등급**: 🥉 홍성 새내기 / 🥈 홍성 탐험가 / 🥇 홍성 박사. 등급을 부스 경품(스티커, 엽서 등)과 연결.
- **오늘의 순위표**: 닉네임(이름 대신 동물·과일 닉네임 자동 생성)으로 그날 상위 10명 표시. **아이의 실명·개인정보는 받지 않음.**
- **결과 QR(선택)**: 오늘 배운 해설 카드 모음 페이지로 연결. 가정에서 다시 보기.

## 5. 콘텐츠(문항) 제작 계획

### 5.1 카테고리별 문항 수 목표 (1차)

### 5.2 문항 예시 (초안, 사실 확인 전)

| 난이도 | 카테고리 | 형식 | 문제 | 정답 | 해설 |
|---|---|---|---|---|---|
| 저 | 특산물 | O/X | 광천의 새우젓은 동굴처럼 생긴 '토굴'에서 익힌다. | O | 토굴은 사계절 온도가 일정해서 새우젓이 맛있게 익어요. |
| 저 | 인물 | 4지 | 「님의 침묵」을 쓴 홍성 출신 시인은? | 한용운 | 만해 한용운은 독립운동가이자 시인이에요. |
| 고 | 인물 | 4지 | 김좌진 장군이 크게 이긴 독립군 전투는? | 청산리 전투 | 1920년 청산리 일대에서 일본군을 크게 물리쳤어요. |
| 고 | 사회 | 4지 | 충청남도청이 있는 홍성의 신도시 이름은? | 내포신도시 | 2013년 충남도청이 대전에서 내포신도시로 옮겨 왔어요. |
| 고 | 역사 | 4지 | 홍성의 옛 이름으로, '홍주성'에도 남아 있는 이름은? | 홍주 | 홍주와 결성이 합쳐져 '홍성'이라는 이름이 되었어요. |
| 저 | 안전 | O/X | 횡단보도 초록불이 깜빡일 때 뛰어서 건너도 된다. | X | 초록불이 깜빡이면 다음 신호를 기다려요. |

### 5.3 문항 데이터 형식 (JSON)

```json
{
  "id": "hs-people-001",
  "region": "hongseong",
  "category": "people",
  "level": "low",
  "type": "choice",
  "question": "「님의 침묵」을 쓴 홍성 출신 시인은?",
  "choices": ["한용운", "윤동주", "김소월", "정지용"],
  "answer": 0,
  "explanation": "만해 한용운은 독립운동가이자 시인이에요.",
  "image": "images/people/hanyongun.png",
  "source": "홍성군 문화관광 누리집",
  "verified": true
}
```

- 교사·담당자가 수정하기 쉽도록 **구글 시트(또는 엑셀)로 작성 → CSV 내보내기 → 변환 스크립트로 JSON 생성** 흐름을 만듦.
- `source`(출처)와 `verified`(검수 완료) 필드가 없는 문항은 게임에 나오지 않게 함.

### 5.4 검수 절차

1. 초안 작성 (개발팀 / 교사)
2. **사실 검증**: 홍성군청 문화관광과, 홍주성역사관, 군 누리집 자료와 대조
3. **교육 검수**: 초등 교사가 학년 수준·어휘 확인 (3학년 사회 "우리 고장" 단원과 연계하면 좋음)
4. 아이 3~5명 대상 시범 플레이 → 너무 어렵거나 헷갈리는 문항 수정

## 6. 화면 · UX 원칙 (초등학생, 행사장 기준)

- **큰 글씨**(본문 28px 이상), 큰 버튼(최소 80×80px), 한 화면에 할 일 하나.
- **글보다 그림**: 장소마다 대표 일러스트, 보기에도 그림 활용.
- **시끄러운 행사장**: 소리 없이도 이해되게 시각 효과(정답 별가루, 오답 흔들림) 우선. 효과음·음성은 볼륨 조절.
- **무입력 30초 → 안내, 60초 → 타이틀로 자동 복귀**: 아이가 중간에 떠나도 다음 아이가 바로 시작 가능.
- **진행자 모드**: 화면 구석을 길게 누르고 비밀번호를 넣으면 난이도 고정, 순위표 초기화, 소리 설정.
- 색약 고려(정답/오답을 색만이 아니라 ⭕❌ 기호로도 표시).

## 7. 기술 구성 (제안)

| 항목 | 선택 | 이유 |
|---|---|---|
| 플랫폼 | **웹 앱(PWA)** | 태블릿, 노트북, 키오스크 어디서든 브라우저로 실행. 설치 쉬움 |
| 언어 · 빌드 | TypeScript + Vite | 빠른 개발, 정적 파일로 배포 |
| 게임 엔진 | **Phaser 3** (보드·미니게임) + HTML/CSS (퀴즈 UI) | 2D 터치 게임에 적합, 자료 많음 |
| 오프라인 | 서비스 워커로 모든 자원 캐시 | 행사장 와이파이 불안정 대비 |

| 음성 | 브라우저 TTS 또는 미리 녹음한 mp3 | TTS 품질이 낮으면 녹음 사용 |

## 9. 행사 운영 계획

- **장비**: 10인치 이상 태블릿 2~3대(거치대), 또는 터치 모니터 + 노트북. 보조 배터리, 예비 기기 1대.
- **회전**: 1판 5~7분 → 기기 1대당 시간당 약 8~10명.
- **보상 연계**: 결과 화면의 등급을 진행자가 보고 경품 지급. 도장 5개 완주자에게 "홍성 탐험가 인증서" 출력(선택).
- **대기 줄 활용**: 대기하는 아이들을 위해 화면 미러링으로 큰 모니터에 플레이 장면 표시.
- **데이터**: 개인 정보 수집 없음. 운영 후 "문항별 정답률"만 익명으로 내보내 다음 행사 문항 개선에 사용.

## 10. 위험 요소와 대응

| 위험 | 대응 |
|---|---|
| 지역 사실 오류 | 출처 필드 필수, 군청·역사관 검수, `verified` 없는 문항 차단 |
| 너무 어렵거나 쉬움 | 저/고학년 분리, 시범 운영 정답률 50~80% 목표로 조정 |
| 1판이 너무 김 | 턴 제한 12턴, 도장 개수 5개 → 운영 중 진행자 모드로 조정 가능 |
| 행사장 네트워크 문제 | 완전 오프라인 실행 |
| 이미지·캐릭터 저작권 | 직접 제작 일러스트 사용, 사진은 군청 제공 자료 또는 공공누리 자료만 사용(출처 표기) |
| 원작 게임 저작권 | 이름·그림·음악은 쓰지 않고 진행 구조만 참고 |

## 11. 결정이 필요한 사항

1. **행사 날짜와 장비**: 언제, 어떤 기기(태블릿 / 키오스크 / PC)로 운영하는지 → 일정과 화면 크기 결정
2. **1인 vs 2인**: 원작처럼 2인 대결을 1차부터 넣을지
3. **장소 이름 확정**: 3.2절 이름 안을 그대로 쓸지, 군청·학교와 함께 정할지
4. **공식 캐릭터**: 홍성군 공식 캐릭터 사용이 가능한지, 자체 캐릭터(홍이·주니)로 갈지
5. **문항 작성 주체**: 교사 협력이 가능한지, 개발팀이 초안을 쓰고 검수만 받을지
6. **그림 작업**: 일러스트 담당자가 있는지 (없으면 무료 에셋 + 단순한 도형 스타일로 시작)
