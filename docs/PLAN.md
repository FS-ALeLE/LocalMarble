# LocalMarble 기획서 — 「홍성 탐험 고고!」

> 지역 행사 부스에서 초등학생이 주사위를 굴려 지도를 돌며, 그 지역 퀴즈와 미니게임으로 지역을 배우는 웹 보드게임.
> 첫 지역: **충청남도 홍성군** · 첫 행사: **2026년 10월 17일(토)**
> 구조 참고: 아케이드 퀴즈 게임 「데이트 퀴즈 고고」(SemiCom, 1998). 지도를 이동하며 장소별 퀴즈와 미니게임을 풀고, 라이프가 줄어드는 구조.

### 확정된 사항

## 2. 핵심 게임 흐름

```
[등록: 소속·별명] → [난이도·말 선택] → [보드 진행 루프] → [결과] → [리더보드] → "다음 친구 차례!" → [등록]
                                        │
                                        ├─ 주사위 굴리기 (1~3)
                                        ├─ 이동 (갈림길이면 방향 선택)
                                        ├─ 도착 칸 이벤트 (퀴즈 / 미니게임 / 찬스 / 쉼터)
                                        ├─ 점수·라이프·도장 갱신
                                        └─ 종료 조건 확인
```

### 2.1 기본 규칙

- **주사위**: 1~3. 큰 주사위를 터치(노트북은 클릭 또는 스페이스바).
- **라이프**: ♥ 3개. 퀴즈 오답 또는 미니게임 실패 시 1개 감소.
- **점수**: 정답, 미니게임 성공, 찬스 카드로 획득. 리더보드 순위 기준.
- **홍성 도장**: 장소에서 **처음 정답**을 맞히면 그 장소 도장 획득.
- **종료 조건** (먼저 해당되는 것)
  1. 도장 **5개**를 모은 뒤 **골인 지점(홍주읍성 조양문)** 도착 → 완주
  2. 라이프 0 → 게임 오버
  3. 턴 제한(기본 12턴) 초과 → 시간 종료
- 어떤 경우든 점수는 리더보드에 기록. 게임 오버 때는 "오늘 배운 홍성 이야기" 요약 카드를 보여 줌.

### 2.2 「데이트 퀴즈 고고」 요소 대응표

| 원작 요소 | 이 게임에서의 대응 |
|---|---|
| 데이트 상대의 호감도 | 안내 캐릭터의 **친해지기 게이지** (행사 버전은 표정 변화만) |
| 장소마다 다른 퀴즈 | 장소마다 **테마 카테고리** 문항 풀 |
| 퀴즈 사이 미니게임 | 일부 장소는 퀴즈와 미니게임 중 랜덤 |
| 라이프 | ♥ 3개 |
| 오락실 점수 경쟁 | **행사 리더보드** (개인 순위 + 소속 대항전) |

> 원작의 캐릭터, 그래픽, 명칭, 음악은 사용하지 않고 구조만 참고합니다.

### 2.3 안내 캐릭터

- **"홍이"와 "주니"**: 홍주(홍성의 옛 이름)에서 따온 이름의 탐험 안내자. 말풍선으로 문제를 내고 해설을 알려 줌.
- 홍성군 공식 캐릭터를 쓸 수 있으면 교체 (군청 확인 필요).

## 3. 등록 · 리더보드

### 3.1 운영 방식: 행사 모드 하나

- 모든 판이 같은 흐름: `등록 → 플레이 → 결과 → 리더보드 → "다음 친구 차례!" → 등록`
- 기기에 프로필을 기억하지 않음. 입력 없이 60초가 지나면 등록 화면으로 자동 복귀.
- 접속 주소 하나: `https://cne-localmarble.vercel.app/` → 서버가 **진행 중인 행사**를 찾아 연결.
- 진행 중인 행사가 없으면 **연습 모드**(등록·기록 없이 플레이). 행사 전 점검용.

### 3.2 등록 화면

```
[소속 입력] → [별명 입력] → [학년 선택(선택)] → [확인: "홍성초 · 날쌘대하 맞나요?"] → 시작
```

**① 소속 — 직접 입력, 미리 넣은 목록 없음**
- 입력칸 하나 + 빠른 버튼 `개인`(소속 없음).
- **자동 완성**: 같은 행사에서 다른 아이가 이미 입력한 소속을 입력 중에 보여 줌 (예: "홍" → `홍성초`). 미리 넣은 목록은 아니지만 같은 학교가 여러 이름으로 갈리는 것을 줄임.
- **이름 정리 규칙**(소속 대항전 집계용): 공백 제거, `초등학교` → `초` 로 통일. 예: `홍성 초등학교`, `홍성초등학교`, `홍성초` → 모두 `홍성초`.
- 2~12자, 금칙어 필터.

**② 별명**
- 2~8자, 한글·영문·숫자만. 금칙어 필터 + "진짜 이름은 쓰지 마세요" 안내.
- **"추천 별명" 버튼**: 홍성 낱말 조합 (`날쌘대하`, `반짝새우젓`, `용감한억새`, `씩씩한조양문`).
- 같은 소속에 같은 별명이 있으면 자동 번호: `날쌘대하#2`

**③ 학년(선택)**: 1~6 버튼. 고르면 난이도 기본값 자동 설정(1~3 → 저학년).

### 3.3 리더보드 (행사 당일만)

| 탭 | 내용 |
|---|---|
| **탐험왕 순위** | 개인 점수 TOP 20 |
| **소속 대항전** | 소속별 **상위 5명 평균** (참여 3명 이상, `개인` 제외) |
| **내 순위** | 결과 화면에서 "128명 중 37등"처럼 표시, TOP 20 밖이어도 보여 줌 |

- 한 판 = 한 기록. 동점이면 도장 수 → 걸린 시간 짧은 순.
- **전광판**: `…/board` 를 큰 모니터에 띄우면 **5초마다 자동 갱신**, 새 기록이 순위에 들어오면 반짝 효과.

### 3.4 서버 · 데이터 (Vercel + Neon)

```
[게임 화면] ──HTTPS──▶ [Vercel Functions /api/*] ──▶ [Neon PostgreSQL]
[전광판]    ──5초마다──▶
[Vercel Cron] ── 매일 새벽 ──▶ 끝난 행사 기록 삭제
```

- DB 접속 주소(`DATABASE_URL`)는 **Vercel 환경변수에만** 저장. 브라우저 코드에는 넣지 않음.
- Vercel 마켓플레이스의 Neon 연동을 쓰면 환경변수가 자동 설정됨.

**API**

| 메서드 · 경로 | 용도 |
|---|---|
| `GET /api/event` | 진행 중인 행사 (없으면 연습 모드) |
| `GET /api/affiliations?q=홍` | 이 행사에서 이미 입력된 소속 자동 완성 |
| `POST /api/players` | 소속·별명 등록 → 플레이 토큰 발급 |
| `POST /api/plays` | 점수 저장 (토큰 필요) → 내 순위 응답 |
| `GET /api/leaderboard?tab=players` / `tab=affiliations` | 리더보드 |
| `POST /api/admin/hide` | 부적절한 별명 숨기기 (진행자 비밀번호) |
| `GET /api/cron/cleanup` | 다음 날 기록 삭제 (Vercel Cron 전용) |

**테이블**

```sql
events   (id, name, starts_at, ends_at, delete_after)        -- delete_after = 2026-10-18 00:00 KST
players  (id, event_id, affiliation_raw, affiliation_key, nickname, grade, hidden, created_at)
plays    (id, player_id, event_id, score, stamps, lives_left, turns, duration_sec, level, finished, created_at)
question_stats (question_id, shown, correct)                  -- 익명 통계, 삭제 대상 아님
```

- 행사가 1건이므로 관리 화면 없이 진행자가 SQL 한 줄로 행사를 등록.

**점수 검사**
- 등록 때 받은 **플레이 토큰**이 있어야 저장, 토큰 하나당 1번.
- 이론상 최고점 초과, 지나치게 짧은 플레이 시간이면 거부.
- 별명·소속 금칙어 서버에서도 검사.

**인터넷 끊김 대비**
- 점수 전송이 실패하면 기기(localStorage)에 보관 → 연결되면 자동 재전송. 화면에 "기록 저장 대기 중" 표시.

### 3.5 기록 삭제와 개인정보

- **10/18(일) 새벽, Vercel Cron이 행사 기록(`players`, `plays`)을 삭제**. 삭제 후에는 문항별 정답률(`question_stats`)만 남음.
- 경품 확인이 필요하면 진행자가 **당일 마감 때** 최종 순위 화면을 캡처하거나 CSV로 받아 둠.
- 받는 정보: 소속, 별명, 학년(선택)뿐. 실명·연락처·사진은 받지 않음.
- 등록 화면 안내: "별명과 소속이 순위표에 보여요. 진짜 이름은 쓰지 마세요. 기록은 내일 지워져요."

## 4. 지도(보드) 설계

### 4.1 형태

- 홍성군을 단순화한 **미니어처 디오라마 지도 그림 한 장** 위에 칸을 배치.
- 순환 경로 + **갈림길 1곳**(행사 버전), 총 **20칸** 내외.
- 서쪽(바다: 남당항) / 중앙(홍성읍: 홍주읍성) / 북쪽(내포신도시, 용봉산) / 남쪽(광천) / 동쪽(홍동, 이응노의 집) 등 **실제 위치 관계 유지**.
- 지도는 화면보다 크게 두고, 말이 움직이면 **화면이 말을 따라 이동·확대**.

### 4.2 장소 칸 (행사 버전 10곳 + 행사 후 추가)

| 장소 유형 | 홍성 이름(안) | 실제 연결 | 테마 / 활동 | 행사 버전 |
|---|---|---|---|---|
| 박물관 | **홍주성 역사관** | 홍주읍성, 홍주의병 | 역사 퀴즈 | ✅ |
| 도서관 | **만해 도서관** | 만해 한용운 (결성면 출생) | 인물·국어 퀴즈 | ✅ |
| 경찰서 | **백야 안전지킴이 경찰서** | 백야 김좌진 장군 (갈산면 출생) | 생활 안전 + 인물 퀴즈 | ✅ |
| 골목길 | **광천 토굴 새우젓 골목** | 광천 토굴 새우젓 | 특산물 퀴즈 | ✅ |
| 경기장 | **홍주 종합경기장** | 홍성 종합운동장 | 미니게임 「대하 잡기」 | ✅ |
| 항구 | **남당항 바다 시장** | 대하·새조개 축제 | 바다·특산물 퀴즈 / 「대하 잡기」 | ✅ |
| 산 | **용봉산 바위길** | 용봉산, 오서산 억새 | 자연·지리 퀴즈 | ✅ |
| 관청 | **내포 도청 광장** | 충남도청 소재지(내포신도시) | 우리 고장 사회 퀴즈 | ✅ |
| 미술관 | **고암 이응노의 집** | 이응노 생가 기념관 | 미니게임 「같은 그림 찾기」 | ✅ |
| 마을 | **홍동 유기농 마을** | 유기농업, 풀무학교 | 환경·농업 퀴즈 | ✅ |
| 시장 | 홍성 전통시장 장터 | 홍성·광천 5일장 | 「장보기 계산」 | 행사 후 |
| 전망대 | 홍성 스카이타워 | 서부면 해안 전망대 | 보너스 칸 | 행사 후 |
| 유적 | 성삼문·최영 장군 이야기길 | 성삼문, 최영 관련 유적 | 인물 짝 맞추기 | 행사 후 |

> ⚠️ 지명·인물·사실은 **홍성군청 문화관광 자료, 홍주성역사관 자료로 반드시 확인**. 위 표는 초안입니다.

### 4.3 특수 칸 (행사 버전)

| 칸 | 효과 |
|---|---|
| **출발 / 골인 (홍주읍성 조양문)** | 도장 5개 이상일 때 지나거나 멈추면 완주 |
| **찬스 ("홍성 보물 쪽지")** ×3 | 점수 +50 / 라이프 +1 / 주사위 한 번 더 / 홍성 상식 쪽지 |
| **쉼터 (정자)** ×2 | 라이프 +1 (최대 3) |

**칸 배분 (20칸)**: 장소 14(10곳, 일부 장소는 2칸) / 찬스 3 / 쉼터 2 / 출발·골인 1

## 5. 퀴즈 · 미니게임

### 5.1 퀴즈 형식 (행사 버전)

| 형식 | 설명 | 대상 |
|---|---|---|
| **O/X** | 큰 버튼 두 개 | 저학년 위주 |
| **4지선다** | 글 보기 또는 그림 보기 | 공통 |
| **사진 보고 맞히기** | 담당자가 준비한 장소·유적·인물 사진 → 이름 고르기 | 공통 |

- 제한 시간: 저학년 20초, 고학년 15초.
- 힌트: 게임당 1회(오답 보기 하나 지우기).

### 5.2 문항 랜덤 배치

1. 장소 칸마다 `category`: `history`, `people`, `safety`, `specialty`, `nature`, `society`, `environment`
2. 게임 시작 시 난이도별·카테고리별로 **섞은 덱** 생성.
3. 칸에 멈추면 그 카테고리 덱에서 **중복 없이** 한 문항. 덱이 비면 다시 섞기.
4. "퀴즈 또는 미니게임" 칸은 퀴즈 70% / 미니게임 30%.

### 5.3 미니게임 (행사 버전 2종)

1. **이미지 생성 도구**: ChatGPT(GPT 이미지) 또는 Gemini 중 하나 (추천과 이유는 ART_GUIDE 참고)
2. **공식 캐릭터**: 홍성군 공식 캐릭터 사용 가능 여부 (불가하면 홍이·주니)
3. **문항 검수자**: 10/10~12에 사실 확인해 줄 사람
4. **시범 플레이**: 10/15에 아이 2~3명 테스트가 가능한지
5. **경품·시상**: 등급별 경품, 소속 대항전 시상 여부
